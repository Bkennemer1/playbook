<div className="step-page-section"> 

  <h2>Overview</h2> 

  <p>The file has cleared underwriting and Arive has notified Emily that the milestone changed. She now owns it through funding.</p> 

  <p>First job: get oriented, then work the file until it satisfies the <strong>CD gate</strong> — the checklist every lender requires before a Closing Disclosure can be issued. Nothing else in closing happens until that gate clears.</p> 

</div> 

  

<div className="step-page-section"> 

  <h2>Getting oriented</h2> 

  <p>There's no handoff conversation. Emily opens the file in Arive and the lender portal and works out where it stands herself. On a straightforward file that's fine. On anything unusual — a closing date that already moved, a difficult title company, a borrower who's been slow — that context doesn't travel automatically.</p> 

  <p>Start by reviewing the CTC approval itself: confirm the loan actually cleared, confirm every condition shows satisfied, and confirm the terms on the approval match what you expect. If anything looks off, ask before proceeding — the LO or Danielle can fill in the gaps in a minute.</p> 

</div> 

  

<div className="step-page-section"> 

  <h2>The CD gate</h2> 

  <p>Every lender requires the same set of items to be resolved before a Closing Disclosure can be generated. The specific list below is UWM's, but <strong>the shape is nearly universal</strong> — expect the same requirements at Kind, PennyMac, Loan Store, and the rest.</p> 

  

  <h3>Our side</h3> 

  <p>These are ours to complete. Most were set up during <a href="/phases/processing/file-setup">file setup</a> — this is where that work pays off:</p> 

  <ul> 

    <li>The loan has been locked</li> 

    <li>Title company information is complete</li> 

    <li>Trust information is complete</li> 

    <li>Borrower email has been completed</li> 

    <li>Settlement agent contact information is complete</li> 

  </ul> 

  

  <h3>The lender's side</h3> 

  <p>These reflect the state of the file itself:</p> 

  <ul> 

    <li>The loan is in Approved with Conditions status or later</li> 

    <li>The appraisal has been cleared by underwriting</li> 

    <li>Taxes have been finalized for the loan</li> 

    <li>The annual premium amount for property insurance is complete</li> 

    <li>There is no pending change of circumstance request</li> 

    <li>The one-business-day waiting period after the most recent Loan Estimate was signed is complete</li> 

    <li>The loan has no pending restructure</li> 

  </ul> 

</div> 

  

<div className="callout info"> 

  <strong>The gate is visible in the lender portal.</strong> Each item shows as satisfied or outstanding, with a timestamp when it cleared. Work the outstanding ones — that list <em>is</em> your task list at this stage. When everything shows green, the CD can be issued. 

</div> 

  

<div className="step-page-section"> 

  <h2>Where these items usually stall</h2> 

  

  <h3>Taxes not finalized</h3> 

  <p>The property tax figure has to be nailed down for the escrow calculation. This traces back to the tax verification Danielle did during file setup — if the figure was estimated rather than verified, it surfaces here.</p> 

  

  <h3>Insurance premium incomplete</h3> 

  <p>The annual premium amount has to be in the file, not just a binder on the way. If HOI is still unsettled, that's the blocker.</p> 

  

  <h3>Pending change of circumstance</h3> 

  <p>Any open COC request freezes the CD. It has to be resolved or withdrawn first.</p> 

  

  <h3>Loan not locked</h3> 

  <p>A floating loan can't produce a CD. If the file is still floating this close to closing, that's a conversation with the LO immediately — not a wait-and-see.</p> 

  

  <h3>The LE waiting period</h3> 

  <p>If a revised Loan Estimate went out recently, the one-business-day clock after signature has to run. Nothing to do but wait — but know it's why the gate is holding.</p> 

</div> 

  

<div className="step-page-section"> 

  <h2>What happens next</h2> 

  <p>Once every gate item clears, the CD gets issued and the three-day clock starts. See <a href="/phases/closing/cd-issued">CD issued &amp; the 3-day clock</a>.</p> 

</div> 

  

<div className="step-page-section"> 

  <h2>Who to ask if you're stuck</h2> 

  <p>A gate item you can't clear: the lender's account executive.<br />Lock status or a floating loan close to closing: the LO on the file, immediately.<br />Missing context on a file that just landed: Danielle or the LO.<br />Taxes or insurance figures: Danielle set these up — start with her.</p> 

</div>
